# Ownership and Credit

This repository is owned and maintained by Kubilay Yildirim unless explicitly stated otherwise.

## Repository ownership

- Repository ownership remains with the repository owner
- Contributor access does not imply shared ownership of the repository itself
- Merge control and project direction remain with the repository owner

## Credit model

Credit is assigned based on actual contribution, including:

- authored commits
- pull requests
- issue ownership
- architecture proposals
- debugging, validation, and technical review

## Contribution record

The primary record of contribution is:

- Git commit history
- pull request history
- issue history
- repository discussions and review comments

## Intent

The intent is honest and open collaboration with clear attribution, visible work history, and retained project control.
