# Collaboration Rules

This repository is maintained as an owner-led engineering project with open technical collaboration.

## Operating model

- The repository owner retains control of the main branch and final merge decisions
- Contributors work through branches and pull requests
- Work should be discussed in issues before major implementation begins
- Significant design changes require prior alignment before code is written

## Branching and merge policy

- Do not push directly to the default branch
- Use feature branches for all work
- Open a pull request for every change
- The repository owner decides when and whether a pull request is merged

## Attribution

Credit is based on visible work, including:

- issue ownership
- commit history
- pull requests
- technical review comments
- design proposals and documented decisions

## Expected conduct

- be honest about what you built
- do not represent another person’s contribution as your own
- discuss major changes before implementing them
- keep collaboration professional and technically grounded

## External reuse

No external redistribution, relicensing, or transfer of the repository contents should be done without explicit agreement from the repository owner and relevant contributors.
